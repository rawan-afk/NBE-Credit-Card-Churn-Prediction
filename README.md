# NBE Credit Card Churn Prediction

Machine learning project for predicting credit card customer churn, developed during my AI internship at the National Bank of Egypt (NBE) in July 2026 under the supervision of Team Lead Shehab El Assal.

## Overview

This project implements an end-to-end machine learning pipeline for identifying customers who are at risk of churning.

The main objective was to develop a predictive model that can identify potential churners early, with particular attention to detecting the minority churn class and analyzing the factors associated with customer attrition.

The repository covers the workflow from data preprocessing and exploratory analysis to ensemble modeling and model evaluation.

## Tech Stack

* Python
* pandas
* NumPy
* scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

## Features

* Exploratory data analysis and visualization of customer behavior and churn patterns.
* Data preprocessing, including missing-value handling, categorical encoding, and numerical feature scaling.
* Baseline machine learning classifier training.
* Ensemble modeling using AdaBoost and a custom stacking ensemble.
* Model evaluation using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
* Analysis of customer and behavioral factors associated with churn.
